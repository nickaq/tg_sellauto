# MV AUTO BOT

Telegram-бот для объявлений об автомобилях в двух группах: №1 — продажа, №2 — аукционы США/Канады.
Python 3.12+, aiogram 3, SQLite, APScheduler.

## Запуск
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env        # заполнить BOT_TOKEN и ADMIN_IDS
.venv/bin/python bot.py
```
1. Напишите боту в личку `/myid`, впишите полученный user_id в `ADMIN_IDS` в `.env` и перезапустите бота.
2. Добавьте бота в обе группы с правом отправлять сообщения и фото. `SALES_CHAT_ID` и `AUCTION_CHAT_ID`
   по умолчанию `@master_vadya` и `@master_vadya_auction`; можно указать числовой ID или команду `/setchat`.

## Работа
Бот управляется только в личном чате и только разрешёнными пользователями. В группах он молчит.
Команды открываются кнопкой слева от поля ввода (список зависит от роли), инструкция в боте: `/help`.

1. `/start` → «Создать публикацию» → выбор типа. Бот задаёт вопросы по одному полю.
2. Отправьте **ровно 10 фото** (по одному или альбомом) и нажмите «Завершить загрузку» — придёт предпросмотр.
3. «Подтвердить и опубликовать», «Запланировать», «Редактировать» или «Отменить».
4. Подтверждение сразу публикует пост: продажу в группу №1, аукцион в группу №2. «Запланировать» просит время
   (`ДД.ММ.ГГГГ ЧЧ:ММ`, часовой пояс из настроек).

В группу уходит один пост: альбом из 10 фото с текстом в подписи. Он собирается в личке администратора, пересылается
в группу, и исходник удаляется: в каналах Telegram сохраняет анимированные эмодзи бота только при пересылке, поэтому
над постом есть подпись «Переслано от» с именем бота. У Telegram подпись ограничена
1024 символами; если текст длиннее, бот покажет, на сколько его сократить, и не даст подтвердить публикацию.
Запланированную публикацию можно перенести, отредактировать, снять с расписания или отменить.
После редактирования её нужно подтвердить и запланировать заново.

### Создание с помощью ИИ
Укажите `GROQ_API_KEY` в `.env` (модель меняется через `GROQ_MODEL`), затем `/ai` или «🤖 Создать с помощью ИИ».
Выберите тип и пришлите текст объявления в любом виде или перешлите готовый пост с фото.

Нейросеть только извлекает значения полей в JSON и ничего не придумывает. Правила распознавания привода, коробок,
двигателей и комплектации лежат в `prompts/mv_auto_rules.md`, их можно менять без правки кода. Значения проходят те же
проверки, что и ручной ввод, а HTML с цитатой, ссылками и датой торгов (ссылка на Google Calendar) собирают шаблоны.
Если данных не хватает, бот задаст один вопрос со списком недостающего. Публикация — после подтверждения человеком.

### Менеджеры
Администратор может добавить менеджеров: `/addmanager <user_id>`. Согласования нет: менеджер сам решает, публиковать
свой пост, запланировать или отменить, и работает только со своими черновиками. Отчёты и сообщения о сбоях получает автор,
уведомления о постах менеджеров администратору не приходят. Администратор управляет настройками и пользователями и может
открыть любой черновик. Любого, кто написал боту, можно добавлять автоматически: `/autoreg on`
(по умолчанию выключено, так как ТЗ разрешает доступ только заранее указанным ID).

## Настройки
`/settings` показывает текущие значения и все команды: пользователи, группы, часовой пояс, ссылки, суффикс
мощности и custom emoji. Изменения влияют только на будущие публикации.

**Custom emoji:** анимированные эмодзи из наборов fitauto и ApplicationEmoji заданы в `DEFAULT_CUSTOM_EMOJI`
(`services/post_generator.py`), заменить значок можно командой `/setemoji ✅ <custom_emoji_id>`. Telegram разрешает их не
всем ботам; если в личке они не применились, пост уходит напрямую с обычными эмодзи и без подписи «Переслано»,
а в отчёте о публикации будет предупреждение.

## Временное скрытие опций
`HIDE_AI=1` в `.env` скрывает создание постов через ИИ, `HIDE_AUCTION=1` — создание и публикацию аукционов. Черновики
аукционов при этом сохраняются. Чтобы вернуть опцию, удалите строку или поставьте `0` и перезапустите бота.

## Тесты
```bash
.venv/bin/python -m pytest
```
Тесты работают без сети и ничего не отправляют в Telegram.

При локальном запуске бот работает, пока включён компьютер. Расписание восстанавливается из SQLite (`data/mv_auto.db`)
при старте. Публикации, пропущенные при выключенном боте, выходят сразу после запуска; если просрочка больше недели,
они получают статус «Ошибка публикации», а автору приходит уведомление.

## Деплой на VPS (Docker)
Подойдёт сервер на Ubuntu или Debian с 1 ГБ памяти. Домен и открытые порты не нужны: бот сам обращается к Telegram.

**1. На сервере:** установите Docker и создайте ключ для доступа к приватному репозиторию.
```bash
curl -fsSL https://get.docker.com | sh
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -N ""
cat ~/.ssh/id_ed25519.pub
```
Добавьте выведенный ключ в GitHub: репозиторий → Settings → Deploy keys → Add deploy key (права на запись не нужны).

**2. На сервере:** скачайте код.
```bash
git clone git@github.com:nickaq/tg_sellauto.git ~/tg_sellauto
mkdir -p ~/tg_sellauto/data
```

**3. На своём компьютере:** остановите локального бота, иначе Telegram вернёт ошибку `Conflict`, и скопируйте настройки
и базу. `SERVER_IP` замените на адрес сервера. База нужна, только если хотите сохранить историю и расписание.
```bash
scp .env root@SERVER_IP:~/tg_sellauto/.env
scp data/mv_auto.db root@SERVER_IP:~/tg_sellauto/data/
```

**4. На сервере:** выдайте контейнеру права на `data/` и запустите бота.
```bash
cd ~/tg_sellauto
chown -R 1000:1000 data
chmod 600 .env
docker compose up -d --build
docker compose logs -f bot
```
В логах должна появиться строка `Бот @... запущен`. После перезагрузки сервера бот стартует сам.

### Обслуживание
Все команды выполняются в `~/tg_sellauto`.

Обновить бота после `git push`:
```bash
git pull && docker compose up -d --build
```
Перезапустить после правки `.env` (одного `restart` мало, он не перечитывает `.env`):
```bash
docker compose up -d --force-recreate
```
Сделать резервную копию базы (появится в `data/backup.db`, её стоит скачивать к себе):
```bash
docker compose exec bot python -c "import sqlite3; s = sqlite3.connect('data/mv_auto.db'); d = sqlite3.connect('data/backup.db'); s.backup(d)"
```
